# 云上实验收尾检查清单

一个可在浏览器里直接打开的静态检查清单，用来在云上实验结束后逐项确认：计算、数据库、网络和存储是否已经释放，避免按需资源漏关。

## 如何使用

1. 用浏览器打开 `index.html`，或启动一个静态文件服务后访问该页面。
2. 按分组勾选已经检查过的项目。
3. 勾选状态只保存在当前浏览器的本地存储中，不会上传到服务器。
4. 需要重新开始时，点击「清空勾选」。

本地预览示例：

```bash
python3 -m http.server 8080
```

然后访问 `http://127.0.0.1:8080`。

## 说明

本项目不含后端，也不调用云账号接口，不能替代费用中心对账。它只是一份可交互的收尾提醒。
